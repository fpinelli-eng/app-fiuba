# App FIUBA (nombre a definir)

Web para estudiantes de FIUBA que reúne en una sola cuenta el avance de la carrera, el armado del cuatrimestre y las reseñas de cursos.

**No es un sitio oficial de la universidad.** Proyecto gratuito hecho por estudiantes.

## Documentación

- [`PRODUCTO.md`](PRODUCTO.md): qué hace la app y por qué.
- [`docs/DISENO.md`](docs/DISENO.md): colores, tipografía y pantallas.
- [`docs/COLABORACION.md`](docs/COLABORACION.md): cómo trabajamos.
- [`CLAUDE.md`](CLAUDE.md): instrucciones para Claude Code.

## Estado

Diseño terminado. En construcción: proyecto base (Next.js + Supabase + Vercel).

## Probar en tu computadora

Con [Node.js](https://nodejs.org) 20 o más nuevo instalado:

```
npm install
npm run dev
```

y abrí http://localhost:3000.
